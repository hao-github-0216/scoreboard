# 計分版 (Scoreboard)

單一 HTML 檔案的即時計分板，支援多項運動。

## 支援項目

| 項目 | 說明 |
|------|------|
| 🏐 排球 | 標準排球計分，支援發球權交換 |
| 🏸 羽毛球 | 標準羽毛球計分 |
| 🏓 匹克球 | 匹克球計分 |
| ⛳ 高爾夫 | 高爾夫計分，每個洞獨立紀錄 |

## 快速使用

### 方式一：線上使用（推薦）
[🔗 點擊打開計分版](https://hao-github-0216.github.io/scoreboard/)

### 方式二：本地使用
1. 到 [原始碼頁面](https://github.com/hao-github-0216/scoreboard) 下載 `index.html`
2. 用瀏覽器直接開啟

## 操作說明

1. 開啟網頁後，選擇你要的運動項目
2. 設定參賽者/隊伍名稱
3. 點 plus 按鈕加分，minus 按鈕減分
4. 所有資料會自動儲存在瀏覽器中

## 常見問題

**Q：換瀏覽器後資料不見了？**  
A：計分資料存在瀏覽器本地（localStorage）。換電腦或清除快取會遺失資料。

**Q：白屏/無法使用？**  
A：清除瀏覽器快取後重試，或在設定頁選擇「清除所有資料」。

## 技術資訊

- 單一 `index.html` 檔案，零依賴
- 支援響應式設計，手機/平板/電腦皆可操作
