# 計分板 (Scoreboard)

即時計分板，支援多項運動。模組化結構，零依賴。

## 支援項目

| 項目 | 說明 |
|------|------|
| 🏐 排球 | 標準排球計分（五戰三勝、發球權交換） |
| 🏸 羽毛球 | 標準羽毛球計分（單打/雙打、封頂 30 分） |\n| 🥒 匹克球 | 匹克球計分（換發計分、0-0-2 雙打規則） |\n| ⛳ 高爾夫 | 高爾夫計分（18 洞、雙桿數賽、自動結算） |

## 快速使用

### 線上使用（推薦）
[🔗 點擊打開計分板](https://hao-github-0216.github.io/scoreboard/)

### 本地使用
1. 到 [原始碼頁面](https://github.com/hao-github-0216/scoreboard) 下載全部檔案
2. 用瀏覽器直接開啟 `index.html`
3. 確保所有檔案在同一目錄下

## 操作說明

1. 開啟網頁後，選擇你要的運動項目
2. 點擊面板可編輯選手/隊伍名稱
3. **點一下面板 = +1**，**上滑 = +1**，**下滑 = -1**
4. 所有資料自動儲存在瀏覽器（localStorage）

## 常見問題

**Q：換瀏覽器後資料不見了？**  
A：計分資料存在瀏覽器本地（localStorage）。換電腦或清除快取會遺失資料。

**Q：白屏/無法使用？**  
A：清除瀏覽器快取後重試。
